# UI Prototype: tuxstack GUI layout

**Question:** What should the tuxstack main panel look like?

**3 variants**, switchable via keyboard (← → arrows) or the floating bar.

## Run

```bash
cargo run --bin prototype-ui
```

## Variants

| Key | Name | Description |
|-----|------|-------------|
| A | Tab-focused | Top tabs for Containers/Images/Compose/Incus |
| B | Dashboard-first | Big overview with metrics + recent activity |
| C | Sidebar nav | Left sidebar with icon nav items |
